Comparison conditions

Lab measurements, not real-user Core Web Vitals. INP is not measured. LCP and TBT can vary with hardware, CPU load, route content and network conditions. A hosting change primarily affects delivery; chart JavaScript and rendering costs require application changes.

Repeat with src/scripts/measure-performance.mjs and --compare=docs/performance/2026-09-30-vercel-baseline.json, using the same Lighthouse and Chrome versions. Compare medians and the saved ranges, not a single run.

Repeat after migration

Run from the repository root on the same machine. Replace YYYY-MM-DD with the capture date. Use the recorded Chrome version (Google Chrome for Testing 145.0.7632.6) and Node version. The tool stays outside project dependencies. Keep full audit reports outside the repository.

npm install --prefix /tmp/evilcharts-performance-tools --no-audit --no-fund --save-exact lighthouse@13.5.0

"/Users/gurbinder/.cache/codex-runtimes/codex-primary-runtime/dependencies/node/bin/node" src/scripts/measure-performance.mjs \
  --url=https://evilcharts.com \
  --label=cloudflare \
  --runs=3 \
  --lighthouse=/tmp/evilcharts-performance-tools/node_modules/lighthouse/cli/index.js \
  --chrome="/Users/gurbinder/Library/Caches/ms-playwright/chromium-1208/chrome-mac-arm64/Google Chrome for Testing.app/Contents/MacOS/Google Chrome for Testing" \
  --output=docs/performance/YYYY-MM-DD-cloudflare \
  --artifacts=/tmp/evilcharts-cloudflare-performance \
  --compare=docs/performance/2026-09-30-vercel-baseline.json
