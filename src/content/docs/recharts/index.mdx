Every Evil chart is built on <Link href="https://recharts.github.io/" _blank={true}>Recharts</Link>, which
renders to SVG through React. Every gradient, pattern, dot, and glow is a real DOM node, styled with the CSS
you already use.

## What that buys you

- **Themeable without JavaScript.** Series colors compile to per-chart CSS variables, so light and dark swap
  with a class — no re-render, no flash.
- **Composable.** Charts are built from parts, not props. Drop in a `<Grid />`, a `<Legend />`, or a second
  `<Area />`.
- **Inspectable.** Open devtools; every element of the chart is right there.

## Choosing an engine

Recharts is the default and the right choice for almost every dashboard. Its ceiling is SVG itself: past a
few thousand points the DOM gets heavy, and some chart types aren't in the library.

That's what the <Link href="/docs/echarts">ECharts</Link> provider is for. Install one engine or the other
per chart — never both — so you ship only what you use.
