## Usage

The composed chart is composible. `<EvilComposedChart>` is the container, and you compose only the parts you need — `<Grid>`, `<XAxis>`, `<YAxis>`, `<Legend>`, `<Tooltip>`, and one or more `<Bar>` and `<Line>` — as its children. Each `<Bar>` carries its own `variant`, `glow`, and `isClickable`, and each `<Line>` its own `strokeVariant`, `curveType`, `glow`, and `isClickable`, so a single chart can freely mix bar and line styles.

```tsx
import {
  EvilComposedChart,
  Bar,
  Line,
  XAxis,
  YAxis,
  Grid,
  Tooltip,
  Legend,
  Dot,
  ActiveDot,
} from "@/components/evilcharts/charts/composed-chart";
```

```tsx
const chartConfig = {
  revenue: {
    label: "Revenue",
    colors: { light: ["#3b82f6"], dark: ["#6A5ACD"] },
  },
  profit: {
    label: "Profit",
    colors: { light: ["#10b981"], dark: ["#34d399"] },
  },
} satisfies ChartConfig;

<EvilComposedChart xDataKey="month" data={data} config={chartConfig}>
  <Grid />
  <XAxis dataKey="month" />
  <YAxis />
  <Legend isClickable />
  <Tooltip />
  <Bar dataKey="revenue" variant="gradient" isClickable />
  <Line dataKey="profit" strokeVariant="dashed" isClickable>
    <Dot variant="default" />
    <ActiveDot variant="colored-border" />
  </Line>
</EvilComposedChart>
```

### Interactive Selection

Add `isClickable` to any `<Bar>` or `<Line>` (and to `<Legend>`) to make those series selectable. Use the `onSelectionChange` callback on `<EvilComposedChart>` to handle selection events:

```tsx
<EvilComposedChart
  data={data}
  config={chartConfig}
  onSelectionChange={(selectedDataKey) => {
    if (selectedDataKey) {
      console.log("Selected:", selectedDataKey);
    } else {
      console.log("Deselected");
    }
  }}
>
  <XAxis dataKey="month" />
  <Legend isClickable />
  <Tooltip />
  <Bar dataKey="revenue" isClickable />
  <Line dataKey="profit" isClickable />
</EvilComposedChart>
```

## API Reference

The chart is composed of several parts. The props below are grouped by the component they belong to.

### `<EvilComposedChart />`

The root container. It owns the data, the shared selection state, the loading skeleton, and the optional brush. Everything visual is composed as its children.

<ApiReferenceWrapper>
  <ApiReference>
    <ApiHeader
      propName="data"
      isRequired
    />
    <ApiContent>
      Data used to display the chart. An array of objects where each object represents a data point.

      type: `TData[]` where `TData extends Record<string, unknown>`
    </ApiContent>
  </ApiReference>

  <ApiReference>
    <ApiHeader
      propName="config"
      isRequired
    />
    <ApiContent>
      Configuration object that defines every bar and line series. Each key should match a data key in your data array, with a corresponding color or color array.

      type: `Record<string, ChartConfig[string]>`
    </ApiContent>
  </ApiReference>

  <ApiReference>
    <ApiHeader
      propName="children"
      isRequired
    />
    <ApiContent>
      The composed chart parts — `<Grid />`, `<XAxis />`, `<YAxis />`, `<Legend />`, `<Tooltip />`, and one or more `<Bar />` and `<Line />`.

      type: `ReactNode`
    </ApiContent>
  </ApiReference>

  <ApiReference>
    <ApiHeader
      propName="className"
    />
    <ApiContent>
      Additional CSS classes to apply to the chart container.

      type: `string`
    </ApiContent>
  </ApiReference>

  <ApiReference>
    <ApiHeader
      propName="curveType"
    />
    <ApiContent>
      The default curve interpolation inherited by every `<Line />`. Each `<Line />` may override it locally.

      type: `"basis" | "basisClosed" | "basisOpen" | "bumpX" | "bumpY" | "bump" | "linear" | "linearClosed" | "natural" | "monotoneX" | "monotoneY" | "monotone" | "step" | "stepBefore" | "stepAfter"`

      default: `"linear"`
    </ApiContent>
  </ApiReference>

  <ApiReference>
    <ApiHeader
      propName="barGap"
    />
    <ApiContent>
      The gap between bars sharing the same category.

      type: `number`
    </ApiContent>
  </ApiReference>

  <ApiReference>
    <ApiHeader
      propName="barCategoryGap"
    />
    <ApiContent>
      The gap between different categories of bars.

      type: `number`
    </ApiContent>
  </ApiReference>

  <ApiReference>
    <ApiHeader
      propName="defaultSelectedDataKey"
    />
    <ApiContent>
      The data key that should be selected by default.

      type: `string | null`

      default: `null`
    </ApiContent>
  </ApiReference>

  <ApiReference>
    <ApiHeader
      propName="onSelectionChange"
    />
    <ApiContent>
      Callback fired when a series is selected or deselected — by clicking a clickable `<Bar />`, `<Line />`, or `<Legend />` entry. Receives the selected data key, or `null` when deselected.

      type: `(selectedDataKey: string | null) => void`
    </ApiContent>
  </ApiReference>

  <ApiReference>
    <ApiHeader
      propName="isLoading"
    />
    <ApiContent>
      Shows a loading skeleton animation with a shimmer effect when data is being fetched.

      type: `boolean`

      default: `false`
    </ApiContent>
  </ApiReference>

  <ApiReference>
    <ApiHeader
      propName="loadingBars"
    />
    <ApiContent>
      Number of bars to display in the loading skeleton.

      type: `number`

      default: `12`
    </ApiContent>
  </ApiReference>

  <ApiReference>
    <ApiHeader
      propName="showBrush"
    />
    <ApiContent>
      When enabled, displays a brush control below the chart for selecting and zooming into a range of data.

      type: `boolean`

      default: `false`
    </ApiContent>
  </ApiReference>

  <ApiReference>
    <ApiHeader
      propName="xDataKey"
    />
    <ApiContent>
      The data key used for the x-axis. Only needed by the brush footer — the axis itself reads its key from `<XAxis dataKey="…" />`.

      type: `keyof TData & string`
    </ApiContent>
  </ApiReference>

  <ApiReference>
    <ApiHeader
      propName="brushHeight"
    />
    <ApiContent>
      The height of the brush preview area in pixels.

      type: `number`
    </ApiContent>
  </ApiReference>

  <ApiReference>
    <ApiHeader
      propName="brushFormatLabel"
    />
    <ApiContent>
      Custom formatter for the brush axis labels.

      type: `(value: unknown, index: number) => string`
    </ApiContent>
  </ApiReference>

  <ApiReference>
    <ApiHeader
      propName="onBrushChange"
    />
    <ApiContent>
      Callback invoked when the user changes the brush selection range.

      type: `(range: EvilBrushRange) => void`
    </ApiContent>
  </ApiReference>

  <ApiReference>
    <ApiHeader
      propName="chartProps"
    />
    <ApiContent>
      Additional props forwarded to the underlying Recharts ComposedChart component.

      type: `ComponentProps<typeof ComposedChart>`

      Read the <Link href="https://recharts.github.io/en-US/api/ComposedChart/" _blank>Recharts ComposedChart documentation</Link> for available props.
    </ApiContent>
  </ApiReference>

### `<Bar />`

A single bar series. Each `<Bar />` is self-contained and generates its own gradient/pattern definitions, so a chart can hold any number of bars — each with its own variant, glow, and clickability.

<ApiReferenceWrapper>
  <ApiReference>
    <ApiHeader
      propName="dataKey"
      isRequired
    />
    <ApiContent>
      The series key. Must exist on both the data rows and the chart `config`.

      type: `string`
    </ApiContent>
  </ApiReference>

  <ApiReference>
    <ApiHeader
      propName="variant"
    />
    <ApiContent>
      The visual style of the bar fill. Applies to this bar only.

      type: `"default" | "hatched" | "duotone" | "duotone-reverse" | "gradient" | "stripped"`

      default: `"default"`
    </ApiContent>
  </ApiReference>

  <ApiReference>
    <ApiHeader
      propName="radius"
    />
    <ApiContent>
      The corner radius of the bar in pixels.

      type: `number`

      default: `4`
    </ApiContent>
  </ApiReference>

  <ApiReference>
    <ApiHeader
      propName="glow"
    />
    <ApiContent>
      Applies a soft outer neon glow to this bar.

      type: `boolean`

      default: `false`
    </ApiContent>
  </ApiReference>

  <ApiReference>
    <ApiHeader
      propName="isClickable"
    />
    <ApiContent>
      Lets this bar be selected by clicking it. When any series is selected, unselected series become semi-transparent.

      type: `boolean`

      default: `false`
    </ApiContent>
  </ApiReference>

  <ApiReference>
    <ApiHeader
      propName="enableHoverHighlight"
    />
    <ApiContent>
      When enabled, hovering over a column dims this bar everywhere else, making it easier to focus on specific data points.

      type: `boolean`

      default: `false`
    </ApiContent>
  </ApiReference>

  <ApiReference>
    <ApiHeader
      propName="barProps"
    />
    <ApiContent>
      Escape hatch for raw props forwarded to the underlying Recharts Bar component.

      type: `ComponentProps<typeof Bar>`
    </ApiContent>
  </ApiReference>
</ApiReferenceWrapper>

### `<Line />`

A single line series. Each `<Line />` is self-contained and generates its own color gradient and glow filter, so a chart can hold any number of lines — each with its own stroke, curve, glow, and clickability.

<ApiReferenceWrapper>
  <ApiReference>
    <ApiHeader
      propName="dataKey"
      isRequired
    />
    <ApiContent>
      The series key. Must exist on both the data rows and the chart `config`.

      type: `string`
    </ApiContent>
  </ApiReference>

  <ApiReference>
    <ApiHeader
      propName="strokeVariant"
    />
    <ApiContent>
      The stroke style for this line.

      type: `"solid" | "dashed" | "animated-dashed"`

      default: `"solid"`
    </ApiContent>
  </ApiReference>

  <ApiReference>
    <ApiHeader
      propName="curveType"
    />
    <ApiContent>
      The curve interpolation for this line. Falls back to the chart's `curveType` when omitted.

      type: `"basis" | "bump" | "linear" | "natural" | "monotoneX" | "monotoneY" | "monotone" | "step" | "stepBefore" | "stepAfter" | …`
    </ApiContent>
  </ApiReference>

  <ApiReference>
    <ApiHeader
      propName="connectNulls"
    />
    <ApiContent>
      Whether to connect line segments across null or missing values.

      type: `boolean`

      default: `false`
    </ApiContent>
  </ApiReference>

  <ApiReference>
    <ApiHeader
      propName="glow"
    />
    <ApiContent>
      Applies a soft outer neon glow to this line.

      type: `boolean`

      default: `false`
    </ApiContent>
  </ApiReference>

  <ApiReference>
    <ApiHeader
      propName="isClickable"
    />
    <ApiContent>
      Lets this line be selected by clicking it. When any series is selected, unselected series become semi-transparent.

      type: `boolean`

      default: `false`
    </ApiContent>
  </ApiReference>

  <ApiReference>
    <ApiHeader
      propName="children"
    />
    <ApiContent>
      Optional `<Dot />` and `<ActiveDot />` composition that adds point markers to this line.

      type: `ReactNode`
    </ApiContent>
  </ApiReference>

  <ApiReference>
    <ApiHeader
      propName="lineProps"
    />
    <ApiContent>
      Escape hatch for raw props forwarded to the underlying Recharts Line component.

      type: `ComponentProps<typeof Line>`
    </ApiContent>
  </ApiReference>
</ApiReferenceWrapper>

### `<Dot />` and `<ActiveDot />`

Point markers composed inside a `<Line />`. `<Dot />` is the resting marker; `<ActiveDot />` is the hovered marker. They render nothing on their own — the parent `<Line />` reads their `variant`.

<ApiReferenceWrapper>
  <ApiReference>
    <ApiHeader
      propName="variant"
    />
    <ApiContent>
      The visual style of the point marker.

      type: `"default" | "border" | "colored-border"`
    </ApiContent>
  </ApiReference>
</ApiReferenceWrapper>

### `<XAxis />` and `<YAxis />`

The category and value axes. Both ship with the chart's flat default styling and forward every Recharts axis prop, so `dataKey`, `tickFormatter`, `tickMargin`, etc. pass straight through. They are hidden automatically while the chart is loading.

<ApiReferenceWrapper>
  <ApiReference>
    <ApiHeader
      propName="dataKey"
    />
    <ApiContent>
      The data key for the axis values.

      type: `string`
    </ApiContent>
  </ApiReference>

  <ApiReference>
    <ApiHeader
      propName="…axisProps"
    />
    <ApiContent>
      Every other Recharts XAxis / YAxis prop is forwarded as-is.

      Read the <Link href="https://recharts.github.io/en-US/api/XAxis/" _blank>Recharts XAxis</Link> and <Link href="https://recharts.github.io/en-US/api/YAxis/" _blank>Recharts YAxis</Link> documentation for available props.
    </ApiContent>
  </ApiReference>
</ApiReferenceWrapper>
