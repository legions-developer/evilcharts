EvilCharts is getting a second rendering engine. The charts you already know are built on
<Link href="https://recharts.github.io/" _blank={true}>Recharts</Link>, and they aren't going anywhere.
Alongside them, an <Link href="https://echarts.apache.org/" _blank={true}>Apache ECharts</Link> provider
is on the way.

## Why a second provider

Recharts renders to SVG through React, which is what makes the Evil look possible — every gradient,
pattern, and dot is a real DOM node you can style. That strength is also its ceiling. ECharts renders to
canvas, which unlocks the things SVG can't reach:

- **Chart types Recharts doesn't have** — chord, beeswarm, sunburst, treemap, network graphs, heatmaps,
  gauges, candlesticks, and geo maps.
- **Scale** — progressive rendering and stream loading keep tens of thousands of points interactive.

## What stays the same

The `chartConfig` you already write is the contract across both engines — same `label`, same `icon`, same
`colors: { light, dark }`. See <Link href="/docs/chart-config">Chart Config</Link>.

The composition API carries over too. You'll still write charts as composed parts rather than a wall of props:

```tsx
<EvilAreaChart data={data} config={chartConfig} xDataKey="month">
  <Grid />
  <XAxis dataKey="month" />
  <Legend isClickable />
  <Tooltip />
  <Area dataKey="desktop" variant="gradient" />
</EvilAreaChart>
```

## Picking an engine

Use the switcher at the top of the sidebar to move between providers. You install one or the other — never
both — so you only ever ship the engine you actually use.
